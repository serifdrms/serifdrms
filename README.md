## 🚀 Featured Projects

### 🎣 AvRadar: Balık Av Rehberi
Location-based fishing conditions app — wind, pressure, sea state and moon phase to recommend the best fishing time windows, with photo-based fish species identification.

**Tech:** Kotlin · Jetpack Compose · Hilt · Retrofit · Room · Open-Meteo Marine API · Gemini API · Google APIs

### 🎙️ Hey Claude
Hands-free wake-word assistant for Android — say "Hey Claude" and Claude opens directly in voice chat mode. Uses a custom-trained on-device wake-word model, listens only while the screen is unlocked, and launches voice mode through Shizuku without any screen-reading permissions.

**Tech:** Kotlin · openWakeWord · Shizuku

### 🧴 Cilt Bakım Takip
Skin care tracking and recommendation app — a skin-type survey at first launch, product and routine tracking with ingredient warnings, and personalized care recommendations. Built as a three-person university team project.

**Tech:** Kotlin · Jetpack Compose · Hilt · Navigation 3
